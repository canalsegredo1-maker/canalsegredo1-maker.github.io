Fazenda Segredo

A Fazenda Segredo é a ferramenta interna do canal. Ela prepara os vídeos e, só depois que o dono do canal assiste e aprova cada um, envia o vídeo, o título, a descrição e a miniatura para o próprio canal Segredo usando os Serviços de API do YouTube.

Ela não é oferecida a outras pessoas, não acessa outros canais e não coleta dados de espectadores.
