Política de Privacidade

Atualizada em 25 de novembro de 2026.

A Fazenda Segredo é um aplicativo de uso interno do canal Segredo (@ContandoSegredos), usado apenas pelo dono do canal.

Uso dos Serviços de API do YouTube

A Fazenda Segredo usa os Serviços de API do YouTube. Ao usar o app, você concorda com os Termos de Serviço do YouTube. As informações tratadas por meio da API também seguem a Política de Privacidade do Google.

Quais dados o app acessa e usa

Com a autorização OAuth do dono do canal, o app usa a API de Dados do YouTube só para: enviar vídeos, títulos, descrições e miniaturas para o próprio canal Segredo (videos.insert e thumbnails.set) e confirmar qual canal está autorizado (channels.list).

O que o app não faz

Não coleta dados de espectadores nem de outras pessoas, não lê comentários ou mensagens, não usa cookies nem rastreamento, não vende nem compartilha dados com terceiros e não usa os dados para publicidade.

Armazenamento e compartilhamento

O token de autorização fica guardado como segredo criptografado no repositório privado do canal no GitHub e só é usado nos envios acima. O app guarda apenas o resultado de cada envio (ID e link do vídeo). Nenhum dado é compartilhado com terceiros.

Como revogar o acesso e apagar os dados

O acesso pode ser revogado a qualquer momento na página de segurança do Google: security.google.com/settings/security/permissions. Ao revogar, o token deixa de funcionar na hora. Para pedir a exclusão do token e dos registros de envio, escreva para canalsegredo1@gmail.com: eles são apagados em até 7 dias.

O uso das informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.
