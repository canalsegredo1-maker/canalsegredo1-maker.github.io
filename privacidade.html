Política de Privacidade — Fazenda Segredo

Atualizada em 25 de novembro de 2026.

A Fazenda Segredo é um aplicativo de uso interno do canal Segredo (@ContandoSegredos). Ele é usado apenas pelo dono do canal.

Quais dados o app acessa

Com a autorização do dono do canal, o app usa a API de Dados do YouTube só para enviar vídeos, títulos, descrições e miniaturas para o próprio canal Segredo e para conferir o status desses envios.

O que o app não faz

O app não coleta dados de outras pessoas, não lê comentários nem mensagens, não vende nem compartilha dados com terceiros e não usa os dados para publicidade.

Armazenamento

O token de autorização fica guardado como segredo criptografado no repositório privado do canal e serve só para os envios acima. O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

O uso das informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado. O app também segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.
